# One shared state for every window

Rune gives each window its own state, but every Bezel window shows the same Library and Sessions, and a Session must move between a Tab and a Session window without reconnecting. Bezel keeps one shared `Bezel` behind an `Rc<RefCell<…>>`; each window's own state is a stand-in holding only what belongs to that window (`Here`: which window it is, its palette, the full-screen reveal), and `App::turn_scope` swaps the shared state into the window's state for each of its turns and back out after. A Session's place (Tab or Session window) is a field of the shared state, so moving it changes no connection. Store replies and engine events land on one channel and are routed by request ID and engine ID to the Session that made them, whichever window shows it. The alternative, a state per window with Sessions handed between them over channels, would have split the Library and every form across windows and made each move a handover of a live `SessionHandle`.
